# صهم — الكاشط المرئي للبيانات

أداة سحب بيانات تعمل داخل المتصفح: **تحدّد البيانات التي تريدها بالفأرة، فتفهم الأداة
النمط وتكرّر السحب على كل العناصر المشابهة في الصفحة وفي الصفحات التالية.**

مثال: افتح صفحة أفلام، انقر على «عنوان الفيلم» ثم «الغلاف» ثم «السنة» ثم «التقييم»،
وحدّد زر «التالي» مرة واحدة — فيسحب صهم بيانات كل الأفلام في كل الصفحات ويصدّرها لك
CSV أو JSON.

---

## ١. التثبيت (دقيقة واحدة)

1. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
2. شغّل **وضع المطوّر** (Developer mode) من أعلى الصفحة.
3. اضغط **تحميل غير مضغوط** (Load unpacked) واختر مجلد `sahm-scraper` (الذي فيه `manifest.json`).
4. ثبّت الأيقونة في الشريط، ثم اضغطها — ستفتح **اللوحة الجانبية**.

> الأداة لا تتدخّل في أي صفحة حتى تفتح لوحتها لذلك التبويب، أو تبدأ سحباً.
> (صفحات النظام مثل `chrome://` ومتجر كروم لا يمكن العمل عليها إطلاقاً.)

---

## ٢. الاستخدام خطوة بخطوة

| الخطوة | ما تفعله |
| --- | --- |
| **١ المصدر** | افتح الموقع، اضغط «الحالية» لالتقاط الرابط، وسمّ المجموعة. |
| **٢ الحقول** | اضغط **«التقاط حقل»** ثم انقر على أول عنصر (مثلاً عنوان الفيلم). تظهر شريط أخضر أعلى الصفحة: أكمل بقية الحقول، ثم اضغط **«تم»** أو `Esc`. |
| **٣ صفحة كل عنصر** | اختياري: فعّله إن كانت البيانات داخل صفحة العنصر نفسها (راجع القسم ٣). |
| **٤ التنقل** | اضغط **«التقاط زر التالي»** وانقر على زر «التالي» في الموقع مرة واحدة. |
| **٥ الحماية** | اترك خيارات الإعلانات والنوافذ مفعّلة (راجع القسم ٥). |
| **٦ التشغيل** | اضغط **«اختبار على الصفحة الحالية»** للتأكد من النتيجة، ثم **«بدء السحب»**. |
| **٧ النتائج** | راقب السجل، ثم صدّر **CSV** أو **JSON**. |

### تفاصيل تهمّك

- **اسم الحقل** يُشتق تلقائياً من صنف العنصر (`title`, `poster`, `year` …) ويمكن تعديله.
- **نوع الحقل** يُخمّن تلقائياً (نص / رابط / صورة / رقم / تاريخ)، ويمكن تغييره يدوياً.
  الأنواع المتاحة: نص، رابط، صورة، رقم، وسيط `src`، تاريخ، خاصية `attr`، `HTML`، **قائمة قيم**.
- **قائمة قيم** = يجمع كل العناصر المطابقة في الحقل نفسه (مثل: كل تصنيفات الفيلم
  `أكشن | دراما | رعب`).
- **«تغيير الصف يدوياً»**: إذا أخطأ صهم في تحديد «الصف المتكرّر» (مثلاً اختار مجموعة وسوم
  بدل بطاقة الفيلم)، انقر على عنصر واحد من الصف الصحيح — تُحدَّث كل المحددات فوراً.
- **«إبراز الصفوف»** يُظهر لك بصرياً ما سيسحبه صهم قبل التشغيل.
- كل حقل يعرض **«مفقود في N صف»** إن لم يوجد في بعض الصفوف (مفيد للكشف عن محدد هشّ).
- يمكنك تحرير **محدد CSS** لأي حقل بنفسك — الأداة تحترم تعديلك.
- مجموعة واحدة لكل موقع تريد سحبه؛ يمكن حفظ عدة مجموعات والتنقل بينها من القائمة العلوية.

## ٣. الدخول إلى صفحة كل عنصر (سحب على مستويين)

كثير من المواقع تُظهر في القائمة عنواناً وسنة فقط، وتُخفي التفاصيل (المخرج، القصة، المدة)
داخل صفحة العنصر. لتلك المواقع:

1. في بطاقة **«صفحة كل عنصر»** فعّل **«الدخول إلى صفحة كل عنصر»**.
2. اضغط **«التقاط رابط الدخول»** وانقر على أي رابط في صف القائمة (غلاف الفيلم مثلاً).
   يُحفظ المحدد **نسبةً إلى الصف** فيعمل على كل الصفوف لا على الصف الذي نقرت عليه.
3. اضغط **«اذهب لأول عنصر»** — يفتح صهم صفحة العنصر الأول نيابةً عنك.
4. اضغط **«التقاط حقول التفاصيل»** وانقر على الحقول داخل صفحة العنصر (العنوان، القصة،
   المدة…)، ثم **«تم»**.
5. ارجع إلى صفحة القائمة واضغط **«بدء السحب»**.

ما يحدث أثناء السحب: يقرأ صهم صفوف القائمة → يدخل صفحة العنصر الأول → يسحب حقول
التفاصيل → **يعود إلى القائمة** → يُكمل العنصر التالي → ثم ينتقل إلى الصفحة التالية.
الصف الناتج **واحد لكل عنصر** ويجمع بيانات القائمة وبيانات التفاصيل.

- حقول التفاصيل تُخزَّن بمفاتيح مُسبَّقة: `title` من القائمة تصبح `detail_title` من
  صفحة العنصر — فلا تتضارب الأسماء في ملف CSV/JSON.
- **«أقصى عدد عناصر يدخلها»** يحدّ السحب؛ `0` = بلا حد. مفيد لتجربة سريعة على ٥ عناصر.
- لا يدخل صهم إلا إلى الروابط التي التقطها من صفوف القائمة، ويعود دائماً إلى رابط
  القائمة نفسه؛ فإن فشل الدخول إلى عنصر سجّل السبب وأكمل الباقي (يظهر العدّاد في
  «فشل N»).
- وجود الحقل في الصفحة قد يتأخّر (محتوى يُحمَّل بجافاسكربت)؛ ينتظر صهم حتى
  `waitMs` ثم يُكمل.

## ٤. كيف «تفهم» الأداة النمط؟

1. كل نقرة تُترجم إلى **محدد CSS مطلق** فريد للعنصر.
2. تُحسب **أعمق أب مشترك** لكل الحقول الملتقطة، ثم يُصعد منه حتى مستوى يتكرّر فيه
   العنصر بين أشقائه — هذا هو **صف البيانات** (بطاقة الفيلم مثلاً).
3. تُشتق لكل حقل **مسارات نسبية** من الصف، ثم تُختبر على كل الصفوف المتشابهة، ويُختار
   المسار الأكثر استقراراً (ونُفضّل أسماء الأصناف على `nth-of-type` الهشّة).
4. عند السحب: تُجمع أبناء الحاوية **المشابهون بنيوياً** للصف النموذجي (تشابه يتسامح مع
   صنف إضافي مثل `highlighted`)، ثم تُصفّى الصفوف التي لا تحتوي الحقول — فتُستبعد
   الإعلانات والفراغات البنيوية تلقائياً.
5. تُزال التكرارات بين الصفحات عبر بصمة لكل صف.

## ٥. الإعلانات والنوافذ المنبثقة

أربع طبقات مستقلة يمكن تشغيلها/إطفاؤها:

| الخيار | ماذا يفعل |
| --- | --- |
| **إخفاء الطبقات المغطّية واستعادة التمرير** | يكتشف النوافذ والطبقات المغطّية (موضع ثابت + z-index عالٍ + تغطية ≥ ٣٠٪ من الشاشة) ويخفيها، ويفكّ قفل التمرير `overflow:hidden` و`pointer-events:none` الذي تفرضه المواقع. يعمل مع تغيّرات الصفحة عبر `MutationObserver`. |
| **منع فتح نوافذ جديدة** | سكربت يعمل في سياق الصفحة (`MAIN world`) يمنع `window.open` أثناء السحب وعند النقر على زر «التالي» — صُمّم ضد نوافذ *pop-under* التي تنطلق من النقرة الأولى. |
| **حجب شبكات الإعلانات** | قواعد `declarativeNetRequest` لـ ٤٠ شبكة إعلانية معروفة (DoubleClick, PopAds, PropellerAds, Taboola…). |
| **النقر على أزرار الإغلاق** | اختياري وغير مفعّل افتراضياً لأن بعض أزرار «الإغلاق» مزيفة وتنقل الصفحة. |

**منطقة محميّة:** لا يُخفى أي عنصر يحتوي الصفوف أو الحقول التي التقطتها، ولا أي عنصر
يبدو محتوى حقيقياً (يحتوي `article/main/form/table` أو نصاً طويلاً مع روابط). يمكن
التحقق فوراً عبر «إبراز الصفوف».

## ٦. حدود يجب معرفتها

- **المحتوى داخل `iframe` أو `Shadow DOM` مغلق** لا يمكن التقاطه (قيد أساسي في كل
  الكاشطات التي تعمل على DOM).
- المواقع التي تعتمد التمرير اللانهائي: فعّل **«تمرير تلقائي»**؛ وإذا لم يوجد زر «التالي»
  سيحاول صهم التمرير لتحميل المزيد.
- حدود السلامة: **٥٠٠ صفحة**، **٢٠٠ ألف صف**، **٤٥ دقيقة** لكل سحب، مع كشف الحلقات
  والتوقّف التلقائي إذا لم يتقدّم زر «التالي».
- وضع «صفحة كل عنصر» أبطأ بطبيعته: تنقّلٌ كامل لكل عنصر (دخول + رجوع)، فاجعل
  `waitMs` صغيراً ما أمكن وابدأ بـ `maxItems` محدود لتجربة الإعداد قبل سحب كامل.
- التخزين محلي بالكامل (`chrome.storage.local`)؛ لا يُرسل شيء إلى أي خدمة خارجية.
- الملفات المحلية `file://` تحتاج تفعيل «السماح بالوصول إلى عناوين الملفات» في
  صفحة إعدادات الإضافة.
- **استخدم الأداة على بيانات يحقّ لك سحبها**: موقع تملكه، بيانات عامة، أو بعد إذن صريح،
  مع احترام شروط الاستخدام وقوانين حماية البيانات. الأداة لا تتجاوز حماية المواقع ولا
  تسجّل دخولاً ولا تحلّ كلمات تحقق (CAPTCHA).

## ٧. أدوات المطوّر

```bat
node tools/check-syntax.js                  :: فحص صياغة كل الملفات + manifest + قواعد DNR
npm install --no-save jsdom                 :: (مرة واحدة) لاختبارات DOM
node tools/test-learn.js                    :: ٢٥ اختباراً لنواة التعلّم والاستخراج
node tools/test-messaging.js                :: ١٤ اختباراً لطبقة الرسائل ودورة الأوامر
node tools/test-panel.js                    :: ١٤ اختباراً للوحة: مسار المستخدم حتى بدء السحب
node tools/test-detail.js                   :: ٩ اختبارات للزحف ذي المستويين في كروم مُحاكى
python tools/make_icons.py                  :: إعادة توليد الأيقونات (بدون مكتبات خارجية)
```

**`test-learn.js`** يعمل على صفحات HTML حقيقية داخل jsdom ويغطّي: اكتشاف الصف المتكرّر،
تجمّد الأصناف، صفوف الإعلانات داخل القائمة، فخ التكرار المتداخل، الجداول بلا مُعرّفات،
الصور الكسولة (`data-src`)، حقول القوائم، وتفرّد المحددات المطلقة.

**`test-messaging.js`** يُشغّل سكربتات المحتوى الحقيقية في jsdom ويحاورها كما تفعل
الخلفية: يتحقق أن مغلف الرسائل (`from:'sw'`) موجود، وأن كل نوع رسالة له مُعالِج في
الطرفين، ثم يرسل `PING` و`EXTRACT` و`CLICK_NEXT` و`PICK_START`… ويتأكد من الردود.
اكتب هذا الاختبار أولاً عند أي عطل «لا يستجيب» قبل البحث في المنطق.

**`test-panel.js`** يُحمّل `panel.html` الحقيقي ويشغّل `panel.js` في jsdom مع خلفية
وهمية، ثم يحاكي مسار المستخدم كاملاً: فتح اللوحة → التقاط الحقول → تفعيل أزرار
التشغيل → الضغط على «بدء السحب» → حالة «جارٍ السحب» → الانتهاء، وكذلك مسار صفحة
العنصر: تفعيل الخيار → التقاط رابط الدخول → تعلّم حقول التفاصيل → البدء. أي عطل في
تفاعل اللوحة (مثل زر يبقى معطّلاً) يظهر هنا فوراً.

**`test-detail.js`** هو الاختبار التكاملي للزحف ذي المستويين: يشغّل `background.js`
الحقيقي في كروم مُحاكى، وسكربتات المحتوى الحقيقية في jsdom، ثم يُجري سحباً كاملاً على
قائمة من صفحتين (٦ عناصر) ويتحقق من: اقتران كل صف برابطه، دخول صهم إلى كل عنصر
والعودة، دمج التفاصيل في الصف نفسه وفي ترتيبها الصحيح، وتسلسل التنقّل
(`قائمة ← عنصر ← قائمة ← … ← صفحة تالية`).

## ٨. خريطة الملفات

```
manifest.json                 تعريف الإضافة (MV3)
rules/ads.json                ٤٠ قاعدة حجب شبكات إعلانية
src/
  background.js               service worker: قيادة حلقة السحب، التخزين، الرسائل
  lib/
    selector.js               محددات CSS مستقرة + قياس تشابه العناصر المتكرّرة
    extract.js                التعلّم (اشتقاق الصف والحقول) + الاستخراج
  content/
    content.js                نقطة الدخول في الصفحة وتنسيق الأوضاع
    picker.js                 الواجهة المرئية للالتقاط (Shadow DOM)
    paginator.js              الانتقال بين الصفحات + كشف التوقّف + التمرير اللانهائي
    popups.js                 كشف وإخفاء الإعلانات والطبقات المغطّية + استعادة التمرير
    popup-guard.js            منع النوافذ الجديدة (MAIN world)
  ui/
    panel.html/.css/.js       اللوحة الجانبية العربية
  icons/                      أيقونات مولَّدة
tools/                        أدوات تطوير واختبار
```
### بنية المهمة (للتفاهم المشترك)

```json
{
  "name": "أفلام",
  "startUrl": "https://example.com/movies?page=1",
  "parentSelector": "#movies",
  "itemSignature": { "tag": "li", "classes": ["movie"] },
  "itemSelector": "#movies > li.movie",
  "fields": [
    { "name": "title",  "type": "text",  "selector": "div.meta > h3.title" },
    { "name": "poster", "type": "image", "selector": "a.poster > img" },
    { "name": "year",   "type": "number","selector": "div.meta > span.year" }
  ],
  "detail": {
    "enabled": true,
    "linkSelector": "a.poster",
    "containerSelector": "article.movie-page",
    "fields": [
      { "name": "plot", "type": "text", "selector": "p.plot" },
      { "name": "dur",  "type": "text", "selector": "span.dur" }
    ],
    "waitMs": 9000,
    "maxItems": 0
  },
  "pagination": { "selector": "a.next-page", "maxPages": 20 },
  "options": { "killPopups": true, "guardPopups": true, "delayMs": 1500 }
}
```
`detail` اختيارية: عند `enabled: true` يدخل صهم إلى صفحة كل عنصر ويسحب `detail.fields`
في صف واحد مع حقول القائمة، وتُحفظ قيمها بمفاتيح مُسبَّقة `detail_`. و`maxItems` تحدّ
عدد العناصر (‏`0` = بلا حد).

## ٩. حلّ المشكلات

| المشكلة | الحل |
| --- | --- |
| «لا يمكن العمل على هذه الصفحة» | أنت على صفحة نظام أو متجر كروم — انتقل لصفحة عادية. وإذا تكرّرت على كل المواقع فقد تكون نسخة قديمة من الإضافة: **أعد تحميل الإضافة** من `chrome://extensions` (زر التحديث) ثم `F5` للصفحة. |
| الالتقاط لا يبدأ بعد تحديث الإضافة | أُعيد تحميل الإضافة أو حدّث الصفحة (`F5`) — يحاول صهم الحقن تلقائياً. |
| استُخرج صف واحد فقط | التقط **حقلين على الأقل** من نفس الصف، أو اضغط «تغيير الصف يدوياً» ثم انقر على الصف الصحيح. |
| «مفقود في N صف» على حقل | بعض الصفوف لا تحتوي هذا العنصر فعلاً — طبيعي. وإذا كان الرقم كبيراً، صحّح محدد الحقل يدوياً. |
| «زر التالي لا يتقدّم» | الموقع يستخدم تمريراً لانهائياً: فعّل «تمرير تلقائي». |
| تظهر نوافذ منبثقة أثناء السحب | تأكد من تفعيل «منع فتح نوافذ جديدة»، وزد التأخير بين الصفحات. |
| البيانات ناقصة أو مكرّرة | تحقّق من «إبراز الصفوف»، وزد التأخير إن كان الموقع بطيئاً في التحميل. |
